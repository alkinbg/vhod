# Vhod

Private internal platform for our residential entrance.

`vhod` brings the daily management of the entrance into one secure place: residents, condominium records, fees and payments, expenses, funds, documents, meetings, maintenance, signals, announcements and a private neighbours-only community.

## Principles

- one entrance only;
- private access by invitation only;
- never a SaaS product;
- financial transparency without public debtor lists;
- official condominium workflows kept separate from informal community activity;
- aligned with the Bulgarian Condominium Ownership Management Act (ЗУЕС) and official MRRB forms;
- simple enough to be useful to every neighbour.

## Stack

- PHP 8.4
- Symfony 8.1
- Doctrine ORM
- MariaDB
- Twig
- Symfony UX Turbo / Stimulus
- AssetMapper
- PHPUnit
- PHPStan
